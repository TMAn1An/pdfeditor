copied into this repository. Versions are the ones pinned in
`package-lock.json` at the time of writing. Check each project for the full
license text (included in `node_modules/<package>/LICENSE` after `npm install`).

## Projects studied as references (no code used)

- **Mozilla PDF.js** and **pdf-lib** — public documentation and APIs.
- **[PDFZero](https://github.com/bevinkatti/PdfZero)** (MIT) — its README was
  read for the general idea of a local-only, PDF.js + pdf-lib, overlay-based
  editor. No code was copied.
- **[flyfield](https://github.com/flywire/flyfield)** (GPL-3.0-or-later) — its
  README was read for the idea of detecting white boxes on forms and filling
  them from CSV. Because of its GPL license, none of its code was copied or
  translated; the box detection here (`src/lib/pdf/detect.ts`) is an
  independent, much simpler implementation built on PDF.js operator lists.

## Sample files

Everything in `public/samples/` is generated by `scripts/make-samples.mjs`
and is synthetic: invented names and numbers, and geometric placeholder
"photos". No real personal data is included.
